# Freight Rate Prediction — Machine Learning Engineer Assessment

## Final approach
The final model is a **CatBoostRegressor predicting freight rate per mile (RPM)**:

`RPM = posted_rate / distance`

The predicted RPM is multiplied by distance to obtain `predicted_rate`.

## Validation strategy
The development data is chronological:
- **Training:** January–September 2025
- **Holdout validation:** October 2025

This avoids random temporal mixing and makes the holdout representative of a future-period prediction task.

### October holdout metrics
- MAE: **$102.79**
- RMSE: **$646.89**
- R²: **0.8209**
- Selected iterations: **170**

## Data quality
- Negative weights were treated as invalid.
- Missing/invalid weights were median-imputed using valid development weights.
- Missing/invalid weight indicators were retained as model features.
- `market_index` and `quote_signal` were excluded from the final model because the fixed December scenario does not contain them.

## Feature engineering
The final model uses:
- pickup, delivery, equipment
- route and route + equipment
- distance transformations
- weight and weight-per-mile
- distance × weight interaction
- geographic distance and coordinate deltas
- calendar and cyclical date features
- missing/invalid weight indicators

## Run
Place the supplied assessment data under `data/` with these names:

```text
data/train_test.csv
data/validation.csv
data/validation-predictions-template.csv
data/december_chart_inputs.csv
```

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Train and generate predictions:

```bash
python train.py
```

Validate the outputs and generate the fixed December chart:

```bash
python score.py --predictions validation_predictions.csv --december-predictions december_chart_inputs.csv
```

The scorer should report 12,000 final predictions and 31 December predictions as valid.
